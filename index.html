🐉 KALI LINUX + WHONIX GATEWAY

Tutorial Completo de Instalação e Configuração

📋 Introdução

Este tutorial apresenta a configuração de um sistema de segurança avançado utilizando:

  • Host: Kali Linux (sistema principal)
  • Virtualização: VirtualBox
  • Gateway: Whonix Gateway (roteamento TOR)
  • Workstation: Kali Linux virtualizado
Este setup fornece uma camada adicional de anonimato, roteando todo o tráfego através da rede TOR. Use responsavelmente e apenas para propósitos legais.

💻 Requisitos do Sistema

Componente Mínimo Recomendado
RAM 8 GB 16 GB ou mais
Processador 4 núcleos 6-8 núcleos
Armazenamento 50 GB 100 GB ou mais
Virtualização Intel VT-x/AMD-V habilitado na BIOS

🔧 PASSO 1: Instalação do VirtualBox

1Atualizar o sistema

sudo apt update && sudo apt upgrade -y

2Instalar VirtualBox

sudo apt install virtualbox virtualbox-ext-pack -y

3Verificar instalação

virtualbox --version

🌐 PASSO 2: Download e Instalação do Whonix

📥 Downloads Necessários

Whonix Gateway OVA Kali Linux OVA

1Importar Whonix Gateway

  1. Abra o VirtualBox
  2. Clique em Arquivo > Importar Appliance
  3. Selecione o arquivo Whonix-Gateway-*.ova
  4. Mantenha as configurações padrão e clique em Importar

2Importar Whonix Workstation (Opcional)

Repita o processo acima com o arquivo Whonix-Workstation-*.ova

🐉 PASSO 3: Instalação do Kali Linux no VirtualBox

1Importar Kali Linux OVA

  1. No VirtualBox, clique em Arquivo > Importar Appliance
  2. Selecione o arquivo kali-linux-*.ova
  3. Clique em Importar

⚙️ PASSO 4: Configuração do Kali Linux Virtual

1Configurações de Hardware

Selecione a VM do Kali Linux e clique em Configurações

🖥️ Sistema

Memória RAM: 6144 MB (6 GB)
Processadores: 6 núcleos

🎨 Vídeo

Memória de Vídeo: 128 MB
Aceleração 3D: Habilitado (opcional)

2Configuração de Rede

🌐 Rede

Adaptador 1: Habilitado
Conectado a: Rede Interna
Nome: Whonix
IMPORTANTE: O nome da rede interna deve ser exatamente "Whonix" para compatibilidade com o Whonix Gateway.

🚀 PASSO 5: Iniciando o Sistema

1Iniciar Whonix Gateway

  1. Selecione Whonix-Gateway no VirtualBox
  2. Clique em Iniciar
  3. Aguarde o boot completo e a conexão com a rede TOR
  4. Você verá mensagens de status da conexão TOR

2Iniciar Kali Linux Virtual

  1. Certifique-se de que o Whonix Gateway está rodando
  2. Selecione a VM do Kali Linux
  3. Clique em Iniciar

🔑 Credenciais Padrão

Usuário: kali
Senha: kali

🔌 PASSO 6: Configuração da Rede no Kali Linux

1Acessar Configurações de Rede

  1. No Kali Linux virtualizado, clique no ícone de rede
  2. Selecione Configurações de Rede ou Edit Connections
  3. Selecione Wired connection 1
  4. Clique em Editar (ícone de engrenagem)

2Configurar IPv4 Manual

  1. Vá para a aba IPv4
  2. Mude o método de Automático (DHCP) para Manual

📡 Configurações IPv4

Address (Endereço): 10.152.152.3
Netmask (Máscara): 255.255.192.0
Gateway: 10.152.152.10
DNS Servers: 10.152.152.10

3Salvar e Aplicar

  1. Clique em Salvar
  2. Feche a janela de configurações
  3. Reinicie a máquina virtual:
sudo reboot

🔄 PASSO 7: Atualização do Sistema

1Atualizar repositórios e sistema

sudo apt update && sudo apt full-upgrade -y

Quando solicitado, digite a senha: kali

2Limpar pacotes desnecessários

sudo apt autoremove -y && sudo apt autoclean

✅ PASSO 8: Verificação da Conexão TOR

1Verificar conexão TOR

curl --socks5-hostname 10.152.152.10:9050 https://check.torproject.org/api/ip

Ou verifique seu IP público:

curl ifconfig.me

2Testar no navegador

  1. Abra o Firefox no Kali Linux
  2. Acesse: https://check.torproject.org
  3. Você deve ver: "Congratulations. This browser is configured to use Tor."
Se você vir a mensagem de confirmação, seu tráfego está sendo roteado através da rede TOR com sucesso!

🛠️ Comandos Úteis

Verificar status da rede

ip addr show
ip route show

Testar conectividade com o Gateway

ping -c 4 10.152.152.10

Verificar DNS

cat /etc/resolv.conf

Reinstalar ferramentas do Kali

sudo apt install kali-linux-default -y

sudo systemctl list-units --type=service --state=running

🔒 Dicas de Segurança

Nunca revele informações pessoais: Mesmo com TOR, evite fazer login em contas pessoais ou revelar dados que possam identificá-lo.
  • Sempre mantenha o Whonix Gateway rodando antes de iniciar o Kali
  • Não instale plugins ou extensões desnecessárias no navegador
  • Desabilite JavaScript quando possível
  • Use o Tor Browser incluído no Whonix para navegação anônima
  • Mantenha ambos os sistemas sempre atualizados
  • Não faça downloads de fontes não confiáveis
  • Considere usar snapshots do VirtualBox para backup

Criar Snapshot da VM

  1. No VirtualBox, selecione a VM do Kali
  2. Vá em Menu > Máquina > Tirar Snapshot
  3. Nomeie e descreva o snapshot
  4. Clique em OK

🔧 Resolução de Problemas

Problema: Sem conexão com a internet

  1. Verifique se o Whonix Gateway está rodando
  2. Confirme as configurações de rede IPv4
  3. Teste a conectividade: ping 10.152.152.10
  4. Reinicie a conexão de rede:
    sudo systemctl restart NetworkManager

Problema: TOR não conecta

  1. No Whonix Gateway, verifique os logs do TOR
  2. Aguarde alguns minutos - a conexão pode demorar
  3. Reinicie o Whonix Gateway se necessário

Problema: Sistema lento

  1. Aumente a RAM alocada (mínimo 6 GB recomendado)
  2. Adicione mais núcleos de CPU
  3. Feche aplicações desnecessárias no host
  4. Considere usar SSD ao invés de HDD
